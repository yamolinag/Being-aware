# Being-aware

## Título y descripción breve

Being-aware es un proyecto de sitio web interactivo que reúne contenido y funciones para usuarios interesados en la conciencia personal y el bienestar. Incluye páginas de noticias, cuenta de usuario, bienvenida y un foro de discusión.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript

## Instalación

1. Clona o descarga el repositorio en tu equipo.
2. Abre la carpeta del proyecto en tu editor de código o directamente en el explorador de archivos.
3. Abre el archivo `index.html` en tu navegador web preferido.

> Si deseas editar el proyecto, usa el editor de tu preferencia (por ejemplo, VS Code) y modifica los archivos `.html`, `.css` y `.js`.

## Uso

- `index.html`: página principal del sitio.
- `news.html`: sección de noticias.
- `cuenta.html`: área de cuenta de usuario.
- `Being_aware_Forum.html`: foro de discusión.
- `welcome.css`, `news.css`, `cuenta.css`, `Being_aware_Forum.css`, `Reset.css`: estilos del proyecto.
- `Welcome.js`, `news.js`, `cuenta.js`, `Being_aware_Forum.js`: lógica y comportamiento interactivo.

### Ejemplo de uso

1. Abre `index.html` en el navegador.
2. Navega a las distintas secciones del sitio usando los enlaces o menús.
3. Revisa la información en `news.html`, gestiona tu cuenta en `cuenta.html` y participa en el foro en `Being_aware_Forum.html`.

> Puedes capturar la pantalla del sitio en tu navegador para documentar el funcionamiento.
